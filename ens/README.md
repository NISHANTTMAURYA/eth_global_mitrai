## Quick Summary
Every MitrAI companion is assigned a subname: `<name>.mitrai.eth`.
Its on-chain **Arkiv** memory key, current mortal stage, owner/guardian, and 3D avatar form are stored in standardized ENS text records, verifiable directly via the app or through the open `/api/ens/[name]` resolution gateway.
