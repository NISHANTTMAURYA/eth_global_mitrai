# VRoid beta sample avatars

Vivi (girl) and Sakurada Fumiriya (boy), by pixiv / VRoid Studio.
Downloaded 6 November 2026 from the madjin/vrm-samples mirror:
- https://github.com/madjin/vrm-samples/blob/master/vroid/beta/Vivi.vrm
- https://github.com/madjin/vrm-samples/blob/master/vroid/beta/Sakurada_Fumiriya.vrm

Both exact files embed VRM metadata declaring licenseName=CC0,
commercialUssageName=Allow and allowedUserName=Everyone.
These are beta CC0 models, distinct from stable AvatarSample_A/B/C
which have additional sample-model conditions and are not CC0.
License: https://creativecommons.org/publicdomain/zero/1.0/
Mirror license explanation: https://github.com/madjin/vrm-samples#license

Each file has 54 humanoid bone mappings and bound A/I/U/E/O facial shapes.
The renderer converts VRM 0 orientation and drives the normalized humanoid
and expression manager, including independent blink and timed speech.
