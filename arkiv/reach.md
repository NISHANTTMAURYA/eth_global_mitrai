# Reach

Target: creators who cultivate original characters, and visitors who discover one through demonstrated behavior and continue its story. Uses remain creator-defined rather than restricted to one assistant category.

The runnable local flow includes creation, approved memories, checkpoints, publishing, isolated audition, enquiries and handover. Studio profiles and their counts are labeled demos. API integration tests use synthetic records; there are no real-user, retention, sales or revenue claims.

Run `npm ci && npm run dev` on Node 22.13+. Hosted trial URL and real tester observations remain pending. Post-Mumbai priorities are user testing, choosing a practical lifespan, hosted durable storage and live transaction evidence.
