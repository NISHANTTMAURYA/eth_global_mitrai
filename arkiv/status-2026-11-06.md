# Arkiv implementation audit — 6 November 2026

**Historical audit, superseded by [current evidence](README.md).** Later on 6 November, the wallet created a real Carrot Kid root and the app switched its private store to Supabase Postgres. Do not use the older SQLite/no-live-write conclusions below as current status.

Implemented code: SDK 1.0.1, named character schema, indexed public discovery, wallet-signed create/patch, signed snapshot verification, current-owner reconciliation, and wallet ownership transfer. The UI exposes Sync to Arkiv and Discover on Arkiv; `npm run query:arkiv` is a reproducible public query. The repository includes LICENSE and all five required schema/judging files.

Local evidence audit: the active SQLite database had zero character records with an `entityKey`. The checked `.env.local` had no configured Rabdi access key. There is no writer-wallet list, transaction receipt or demonstrated live visible read to cite. Therefore the integration is implemented but not demonstrated end to end, and the current build must not claim that the Arkiv track qualification is complete.

The current [Mumbai prize requirements](https://ethglobal.com/events/mumbai/prizes#arkiv) require an actual current-testnet write and a user-visible feature reading Arkiv, writer addresses, a runnable query, `/arkiv/schema.md`, the four criterion files, a public licensed repository and AI-use disclosure. Rabdi is the network listed on the prize page. Code installation or unused logging alone does not qualify.

The character's transferable public identity, general traits, approved memories and lifetime/ownership checkpoint belong on Arkiv. Private chats, inferred personal context, email addresses, push subscriptions, outreach schedules and prior-owner relationship evidence remain in SQLite. Cognition and the delivery worker run off chain. Applying private-derived general traits requires a deliberate local checkpoint; publishing that checkpoint remains a wallet-signed operation. Storage expiry is 90 days in the existing write path; a character's fixed lifespan and Sunset are separate. Auto-renewal and append-only on-chain history remain outstanding.

Product work can continue before chain deployment. The final demo still needs a funded user-controlled test wallet, a write, public discovery/read, ownership transfer evidence and a hosted durable app. No live wallet transaction was attempted in this audit.
